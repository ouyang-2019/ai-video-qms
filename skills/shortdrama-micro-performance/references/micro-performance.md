# 微表演检查表

微表演的质量目标是让观众从可见行为读出人物状态，而不是让提示词宣布情绪。

每个角色至少记录：

- 目标：此刻想得到什么。
- 阻碍：谁或什么让目标受阻。
- 刺激：具体听到、看到、碰到或意识到的信息。
- 基线：刺激前的脸、身体、呼吸、视线和手部状态。
- 节拍：按时间写身体、视线、面部、呼吸、手部、台词或无对白。
- 余韵：动作后的保持、回避、补救或状态变化。

常见失败：

- 只有情绪标签，没有眼神、身体和呼吸。
- 反应早于刺激，或上一镜状态没有承接。
- 嘴部动作与台词、吞咽、叹气重叠冲突。
- 让听者无反应，导致对白像朗读。
- 道具、站位、手部接触在表演中消失。
- 把来源案例的年龄、角色、机位或模型默认值继承到当前项目。
