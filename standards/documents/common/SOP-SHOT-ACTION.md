# SOP-SHOT-ACTION 动作拆解与接触关系作业指导

版本：1.0.0；层级：L3；发布：内部试运行；验证：结构审查。

## 适用与输入
适用于日常动作、追逐、打斗及术法表现。输入剧情目标、角色资产、场景布局、动作结果与已知限制。先使动作可理解，再增加速度和视觉效果。

## 具体步骤
1. 写起始状态：谁在何处、朝向哪里、重心和持物方式、与目标的距离关系。
2. 写动作过程：施动主体、身体或物件运动方向、关键姿势变化与先后；并行动作注明主次。
3. 写接触事件：接触双方、接触部位、发生时点及受力方向；无接触动作明确“无接触”，不虚构碰撞。
4. 写结束状态：人物位置、姿态、物品归属和环境变化；结果必须能够由前述过程产生。
5. 标注摄影机位于行动轴的哪一侧、画面运动方向、景别及主体遮挡；运镜不得使关键接触不可判定。
6. 动作过密时按因果切成准备、发生、结果等镜头，每镜末态成为下一镜初态。特效绑定施动或接触事件。

## 输出格式
使用 TPL-SHOT-IR，填写起始／过程／接触／结束四栏，以及主体方向、摄影方位、画面方向和参考职责。时间使用计划锚点，待目标模型转换。

## 检查与失败修复
检查肢体与物品轨迹连续、接触有结果、角色未无因换位。命中不清先调整遮挡和机位；角色瞬移先补过渡或改分镜；镜头与主体同时复杂运动时减少一方；不要只添加“真实、流畅”等形容词代替具体修复。

内部作业规范；结构审查不等于成片实测。
