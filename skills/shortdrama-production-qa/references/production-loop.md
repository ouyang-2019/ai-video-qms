# 短剧生产闭环

短剧质量不是“提示词写得长”，而是每个阶段的输入、输出、证据和放行条件清楚。

阶段产物：

- 剧本：本集任务、人物目标、冲突策略、对白归属、节奏和结尾承诺。
- 资产：角色身份、角色三视图、表情/动作参考、服装、道具、空场景、站位、声音身份。
- 分镜：镜头编号、时长、机位、动作窗口、表演节拍、首尾状态、参考职责。
- 模型提示词：目标模型元组、必要引用、正向动作描述、限制项、禁止继承项、输出验收点。
- 审核：技术检查、原速观看/听审、缺陷时间码、影响范围、修复建议。
- 返修：最小改动、保持项、候选版本、复验结果和接缝检查。
- 归档：母版SHA、交付版本、记录模板、未检项和后续改进。

不要混淆四种状态：结构输入通过、人工批准、平台执行、视听验收。文本写好只能说明结构和方法准备完成；真实画面、声音、口型、动作自然性和连续性必须看对应版本。
