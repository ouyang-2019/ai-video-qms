# 模型与技法资格验证表

本表逐个模型/版本/平台/模式以及技法填写，图像模型同样适用。官方能力声明与项目实测结论分栏，未提供官方边界或实际输出时不得认定支持。

| 项目 | 记录 |
| --- | --- |
| 模型/版本/平台/模式；技法与目标 | 待填 |
| 官方来源URL、revision、SHA、对应条款 | 待填 |
| 测试用例、初始素材、参数、提示词及各自SHA | 待填 |
| 可观察验收条件、不可接受缺陷 | 待填 |
| 每次尝试ID、输出文件/SHA、耗时、成本、失败原因 | 未执行 |
| 结构状态 / 请求执行状态 / 视听状态 | 未检验 / 未执行 / 未检验 |
| 总尝试数、可检查输出数、合格数与排除原因 | 未执行；不得填零冒充完成测试 |
| 复核者、日期、适用限制、再验证触发条件 | 待填 |

逐次保留失败和成功结果，不能仅记录最佳一次。模型版本、平台转换、输入模式、核心参数或素材类型改变时重新判断资格。资格只对记录的条件成立；镜头中微表情、动作接触、遮挡和声音分项评判，不以接口成功代替可见结果。

空白受控试运行表单；没有填入实际证据时不得判定通过。
