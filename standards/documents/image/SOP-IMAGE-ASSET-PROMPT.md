# 图像资产提示词选择、装配与定点返工作业指导

## 适用与交付目标

适用现有 GPT Image 2 固定版本、OpenAI Images API 的 T2I / EDIT；图像制作使用 assets 阶段。四种用途是三视图、人物图、场景图、分镜图，不能因同样出现“人物”就互换模板。已有身份、场景、摄影和分镜规范继续有效，本文件负责把项目需求和外部示例装成一次可执行的图像任务。

交付最小集合：选例理由、项目变量、参考职责表、完整提示词、独立模型参数、检查清单、FR-IMAGE-JOB记录。用户只要提示词时输出这些准备内容，实际图片和响应字段保持未执行，不为填满记录发起生成。

## 1. 先定用途，再选少量来源

先填写资产用途、主体数量、输出是一张单画面还是视图板、画面比例、后续用于身份参考/场景参考/分镜沟通/首尾帧。按用途筛选案例和模板，候选优先满足以下顺序：参考输入形态相同、构图结构相符、主体与空间复杂度相近、表达风格接近。不以点赞、编号先后或“工业级”自述代替适用性。

先实际读取一个最接近模板的完整正文；需要另一个案例时，说明它仅补哪一项。若没有直接匹配，记录“无直接案例，使用内部模板”，不编造出处。每个选中项记录source_id、case/template ID、原始路径或URL、commit、正文SHA、采用方法与未采用内容。不能只读标题就写“已全文复核”，不能只见成品图就声称已验证原提示词效果。

## 2. 去掉案例内容，保留可复用方法

把来源分成：画面组织方法、项目变量、平台能力自述、无关发布文字。只采用适合当前任务的组织方法；原案例品牌、真人/角色名字、特定台词、标志、故事地点、互动数据与水印不得默认继承。项目有明确授权和创作要求时才填对应内容，并记录来源。删除“8K”等与真实参数不一致的口号；画面里的JSON键、UE风格等不是API参数或执行引擎证明。

中文提示词可直接使用；可见文字逐字列出，不为套用英语示例擅自翻译台词。输出无可见文字时明确写无文字，不能留下占位符让模型猜。

## 3. 冻结身份和参考职责

参考表逐张写实际路径、SHA、输入序号、职责及不可继承项。职责可为身份、服装、姿态、场景布局、材质或构图；一个参考不要含糊承担互相冲突的职责。角色参考与服装参考不同，须明确谁锁脸、谁只提供衣装。缺少已批准身份图可选择T2I建立候选母版，但只能写“新角色探索”，不可冒称延续既有人物。

先列不可变量：脸部轮廓与比例、发型体积、体型、左右标记、衣装结构；再列本轮可变量：角度、姿势、表情、光线或背景。EDIT实际输入存在后才能写图1/图2；T2I不引用未上传图片。保留区、修改区和遮挡关系应可检查。

## 4. 四用途装配规则

| 用途 | 必须解决的问题 | 使用模板 |
|---|---|---|
| 三视图 | 正侧背方向、同尺度基线、左右对应、隐藏面设计 | TPL-IMAGE-TURNAROUND |
| 人物图 | 身份可辨、当前身体状态、构图用途、服装道具接触 | TPL-IMAGE-PORTRAIT |
| 场景图 | 世界方向、地标拓扑、尺度、动线、光源与可变状态 | TPL-IMAGE-SCENE |
| 分镜图 | 某个确定瞬间、机位与轴线、主体关系、与前后镜衔接 | TPL-IMAGE-STORYBOARD |

三视图先查SOP-ASSET-TURNAROUND及SOP-V2-CHARACTER-SHEET；场景先查SOP-ASSET-SCENE及SOP-V2-SCENE；分镜先查PR-STORYBOARD、TPL-SHOT-IR和适用的摄影/站位SOP。仅加载当前缺项涉及的专业内容，不把所有专业词汇塞入同一提示词。

将抽象情绪转为这一帧能看到的线索：视线落点、眼睑、嘴唇、肩颈、手指、重心；不得写只有心理解释而无画面落点的“他感到失落”。强弱和持续变化属于分镜时间轴，单图仅取一个状态。运镜在单图中转为当前相机位置、方向、景别与遮挡，不要求一张图同时完成推拉摇移。

## 5. 请求前检查与交接

核对模板变量全部替换、主体数量与视图数量、参考序号、左右基准、可见文字和输出用途；约束冲突时先修设计。T2I与EDIT依现有模型SOP分别组请求，尺寸、质量、数量、格式在参数栏设置，不能从提示词营销用语推断。多格板用于设计审查；交给视频模型前按其参考规范决定使用单视图、裁切或重做，不能默认整张板可直接作视频参考。

提示词和参数分别保存SHA；FR-IMAGE-JOB填写request_prepared。未执行时生成ID、实际图片SHA、视觉结论留空或not_checked。

## 6. 看图验收、定位缺陷与返工

实际生成后使用FR-IMAGE-INSPECTION逐图比对母版与任务清单。拒收关键缺陷：身份改变、左右镜像、视角错误、关键道具归属错误、空间地标矛盾、非目标文字、肢体接触不成立。漂亮、清晰或分辨率正确不能抵消这些缺陷。

每轮记录“缺陷位置—预期—实见—可能原因—唯一必要修改”。先修身份和空间，再修姿态/接触，最后材质和装饰；避免重写全部提示词制造新变量。例：侧面肩饰换边，保留脸、发型、衣服与其他视图，只修角色身体右侧肩饰的可见/遮挡关系。复验同时检查目标缺陷是否消失、原合格区域是否被破坏。不能定点修复时退回设计或拆成单视图，登记失败尝试，保留父输出与新输出SHA。
