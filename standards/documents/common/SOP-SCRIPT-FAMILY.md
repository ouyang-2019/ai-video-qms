# SOP-SCRIPT-FAMILY 家庭Q版喜剧剧本作业指导

版本：1.0.0；层级：L3；发布：内部试运行；验证：结构审查。

## 适用与输入
适用于以家庭关系、日常误会和夸张表演为主要表达的 Q 版喜剧。输入需求单、家庭成员关系、角色习惯、视觉尺度及已发生事件。Q 版是表现风格，不自动意味着儿童受众，受众要求以需求单为准。

## 具体步骤
1. 选择一个生活目标，如抢遥控器、藏零食或完成家务，确定一位主要推动者及其习惯性弱点。
2. 让人物采用符合性格的解决办法，并因这个办法制造可见的新麻烦；避免用无因巧合替代推进。
3. 设计铺垫与回收：先出现一个普通物件、口头约定或动作习惯，后续让它产生出乎预期但可解释的效果。
4. 把笑点写成“期待建立—短暂停顿—结果偏转”的声画事件，注明反应者和动作落点。
5. 夸张只放大既定性格；核对家庭成员之间的情感底色，冲突后留出关系变化或情绪回收。
6. 演读对白，给表情和反应镜头留空间；记录本集形成的新约定，避免下集无说明遗忘。

## 输出格式
使用通用剧本模板，额外列出生活目标、误会来源、铺垫物、笑点动作、反应角色和结尾回收。每个笑点对应具体场次。

## 检查与失败修复
检查不依赖说明文字时能否看懂笑点；对白抢先解释结果时后移或删除；连续夸张造成节奏平坦时加入平静铺垫；人物为笑点违背既定动机时重设行动。涉及危险模仿的表现须按已确认受众要求调整，不以喜剧风格免除内容审核。

内部作业规范；结构审查不等于成片实测。
