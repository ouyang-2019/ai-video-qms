# SOP-ASSET-TURNAROUND 角色三视图设计作业指导

版本：1.0.0；层级：L3；发布：内部试运行；验证：结构审查。

## 适用与输入
用于建立角色正面、侧面和背面的统一设计基准。输入角色身份、体型比例、服装、发型、饰品、视觉风格及已批准身份参考。本 SOP 不规定某模型必须支持三视图拼图输入。

## 具体步骤
1. 建立身份不变量：年龄观感、头身关系、面部轮廓、发型体积、主配色及独特标记；把情绪和姿势分开记录。
2. 选择中性站姿、统一比例与视平基准，明确侧面为左侧或右侧；三视角均保留完整身体和关键附件。
3. 将服装结构拆成前后可对应部分，注明纽扣、腰带、纹样、武器佩挂及不对称标记的真实左右。
4. 编写三个视角的设计要求，共用身份段，仅改变观察方向；再交给实际图像模型 SOP 生成或绘制。
5. 逐项比对肩宽、身高、鞋型、袖长、发束、配色和附件；镜像问题回到设定修复，不能只改标签。
6. 验收后保存主资产与单视角衍生文件，记录父资产、裁切方法及用途。视频参考图按其专用规范重新选择。

## 输出格式
使用 TPL-ASSET，附身份不变量表、正／侧／背视角说明、左右标记、实际资产路径及检查结论。未生成时路径留空并标“设计完成、图像待生成”。

## 检查与失败修复
轮廓一致而脸部漂移时以已批准身份参考重做相关视角；服装背面被随意补全时先补设计；遮挡导致无法判定时追加局部图。三视图通过只表示设计一致，不证明后续视频身份稳定。

内部作业规范；结构审查不等于成片实测。
