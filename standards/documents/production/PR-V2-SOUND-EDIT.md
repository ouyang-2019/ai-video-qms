# 对白声音与剪辑整合程序

## 目的
将对白、环境、动作音效、音乐和剪辑组织成与画面共享事件时间线的设计。说话语气通过语速、重音、起声、停顿和句尾呈现；情绪解释只作辅助。是否原生生成声音、保留参考音轨或后期配音属于实施路径，必须按实际模型和制作资源选择。
## 输入与职责
编剧提供准确台词、语义与潜台词；表演设计提供发声目的和呼吸节拍；声音设计提供角色声线、拟音材质和空间；剪辑负责信息与动作的衔接。取得目标时长、对白授权版本、镜头表和关键接触时间，缺少音频时以实读或节拍草案估时。
## 程序
1. 分离固定声线身份和当场说话方式；写出说话者、听者、语言、台词原文、重音词及停顿位置。
2. 对每个句子检查呼吸容量与可用时间，超时先压缩台词或增加镜头，不用过度加速牺牲可懂度。
3. 分轨设计对白、拟音、环境、音乐。标出画内或画外声源、远近、遮挡、混响及相对前后景，避免所有层都抢主位。
4. 对口型镜头设置台词起止与头部运动；多人对白明确当前发声者和听者反应。出现无法稳定对齐时选择短句、反应镜头或后期配音方案。
5. 以事件而非只按等长切点安排剪辑，检查接动作、视线、出入画方向及声音跨切；音乐需要持续时使用统一时间线管理。
6. 先听对白可懂度，再检查拟音时序和空间，最后看配乐是否遮住关键信息。声画组合后重新观看，不能用单轨合格代替整片验收。
## 放行与修正
合格设计应能指出每次重要声音来自什么、何时发生、为什么在这里剪。正例：钥匙碰桌短响先起，切到听者停止翻页，房间底噪贯穿切点。反例：每个新镜头都重新启动同一段音乐，造成连续空间像多次开场。
## 记录
保存对白版本、发声标记、声音事件表、混音优先级、剪辑决策表及实读或生成测量结果。无音频试听不填写声音已验收。

## 适用和证据边界

本文件是内部创作与检查规范，发布表示可以试用，不表示已经通过真实视频生成验证。时间、距离、强度等数值是本镜头的设计变量，需按画幅、角色比例、实测可辨性及目标模型调整。模型是否支持参考类型、音频、首尾帧或专用参数，由系列规范和具体平台版本确认；本文件不授予这些能力。
