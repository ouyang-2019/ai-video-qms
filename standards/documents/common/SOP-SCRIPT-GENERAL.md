# SOP-SCRIPT-GENERAL 通用剧本编写作业指导

版本：1.0.0；层级：L3；发布：内部试运行；验证：结构审查。

## 适用与输入
适用于原创单集及系列剧本，接收需求单、角色档案、历史集记忆和创作边界。改编任务另附授权范围；参考作品只提取可抽象的方法，不直接替换姓名复用其独创情节和台词。

## 具体步骤
1. 用一句话写清“谁想得到什么，被什么阻挡，必须作何选择”。若只有题材或气氛，补出可发生的事件。
2. 把主线拆为进入情境、冲突升级、选择行动和结果变化。每场至少产生一项新的事实或关系变化。
3. 为每位人物区分公开目标、当下情绪和已知信息；不得让人物提前掌握未得知的秘密。
4. 按场次写时间、地点、出场人物、可见动作和对白。将抽象评价改写为可表演行为，保留必要留白。
5. 演读对白并检查镜头空间，记录预估时长与依据；不得仅以字数证明最终片长。
6. 对照旧集检查关系、称谓、时间、道具和伏笔；输出新增事实、事实失效项、未解决事项及来源场次。

## 输出格式
使用 TPL-SCRIPT。每场记录场次编号、进入状态、叙事目标、动作／对白、离场状态；文末附版本变化与跨集记忆增量。

## 检查与失败修复
检查目标是否明确、升级是否由人物行动引起、转折是否有前因、结尾是否兑现本集承诺。只有解释没有事件时改为行动；对白重复画面时删去重复信息；设定冲突时回溯原始记录，提出显式修订；原创或授权存在疑问时登记待核验内容，停止将该段标为可发布。

内部作业规范；结构审查不等于成片实测。
