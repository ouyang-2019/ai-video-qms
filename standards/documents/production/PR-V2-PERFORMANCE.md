# 角色表演设计与排演程序

## 目标与分工
本程序把人物内在任务转化为脸、眼、呼吸、姿势、手部活动及声音中可观察的变化。心理词可以保留在导演解释层，但用于生成的主要描述必须包含动作对象、变化触发和结束状态。表情库提供可选择的动作方案，不提供人物真实情绪或说谎的诊断。
## 输入
取得人物身份锚点、身体比例、习惯动作、声音身份、关系和场景目标；确认镜头景别、身体可见范围、对白文本以及手上正在处理的物件。缺少特写时不把极小面部动作作为唯一剧情线索；身体被遮挡时改选当前画面中可读的表现渠道。
## 程序
1. 给人物写“对谁做什么以获得什么”的当场任务，定义失败代价与可更换的策略。
2. 先锁定重心、节奏、开放程度及呼吸基线，再为每个转折选择一到两个主表演渠道；其他部位维持身份与惯性。
3. 将情绪意图改写为触发—可见反应—自我控制—残留状态。听者的变化由听到或看到的刺激触发，避免等自己台词开始才活动。
4. 需要面部细节时，采用眉、眼睑、嘴角、下颌等可见描述；AU代码仅为可选创作缩写，并附自然语言说明和本素材验证状态。
5. 为对白排出吸气、起声、重音、停顿和句尾，核对手势与嘴部动作是否争夺同一时段；有意反差需说明其戏剧作用。
6. 做无声观看与只听声音两次检查，前者检验行为线索，后者检验语义、声线和节奏，再检查组合是否重复解释。
## 质量闸口
关键转折必须有至少一个在当前景别可辨的动作证据；人物不能在相邻镜头无原因复位。没有生成素材时，只能通过纸面排演，不记录“微表情已实现”。如嘴角细节不可辨，优先调整景别或换成手部停顿，不叠加十个表情形容词。
## 输出
交付角色表演基线、逐节拍表演轨、声线基线、镜头适配说明以及失败修复记录。例：“听见价格时，数硬币的拇指停住，吸气后把最后一枚移回掌心”，同时表现取舍和行为目的。

## 适用和证据边界

本文件是内部创作与检查规范，发布表示可以试用，不表示已经通过真实视频生成验证。时间、距离、强度等数值是本镜头的设计变量，需按画幅、角色比例、实测可辨性及目标模型调整。模型是否支持参考类型、音频、首尾帧或专用参数，由系列规范和具体平台版本确认；本文件不授予这些能力。
