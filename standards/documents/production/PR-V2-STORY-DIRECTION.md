# 编剧与导演意图转译程序

## 目的与交接边界
编剧交付观众可以理解的事件因果，导演决定信息何时、从谁的视点被看见。两者共用场景目标，但分别管理故事内容与呈现方法。故事草稿不能仅替换成镜头术语后宣布完成；分镜若暴露剧情因果缺口，退回具体剧本版本修订。
## 输入与责任
输入包含项目受众、篇幅、世界规则、角色目标、场景时间地点、对白草稿与不可修改事实。编剧负责目标—阻碍—选择—后果；导演负责观众信息顺序、表演任务、空间关系、视听重音；审阅者负责验证每个镜头的叙事必要性。小团队可以由同一人承担角色，但评审时仍逐项执行这些职责。
## 程序
1. 建立场景事实表，区分观众已经知道、角色已经知道和本场新揭示的信息。把“气氛紧张”展开为即将失去的具体东西。
2. 将场景拆成由事件触发的节拍，记录节拍前后的目标、策略、控制权和道具状态；无变化的段落合并或删去。
3. 对每个节拍选择主要可见行为与听觉线索，先做无旁白复述，检查是否仅靠心理描写成立。
4. 导演为建立、推进、揭示、反应和过渡镜头分别说明目的，选择说者或听者作为当下信息中心。
5. 编剧和导演共同检查节奏，台词朗读与动作预演的总时长超过目标时，删减事件或拆镜，不通过加速所有动作强行塞入。
6. 锁定场景版本后下发分镜与表演任务；任何更改结局、线索或角色动机的分镜改动，写入变更记录并回流编剧。
## 放行与返工
放行证据包括一条完整因果链、可见节拍表和逐镜目的。例：母亲看见玩具裂缝→孩子遮住玩具→母亲递出胶带→孩子松开手，信息与行为逐步推进。反例：双方先后说“我很难过”“我理解你”，画面始终不动。返工时明确缺失的是事件、反应还是信息，不用“更有戏”代替修改指令。
## 记录
保存场景编号、剧本版本、节拍表、导演阐述、删并镜原因、对白实读时长和交接人。所有后续镜头引用锁定版本；未解决的事实冲突标为待处理。

## 适用和证据边界

本文件是内部创作与检查规范，发布表示可以试用，不表示已经通过真实视频生成验证。时间、距离、强度等数值是本镜头的设计变量，需按画幅、角色比例、实测可辨性及目标模型调整。模型是否支持参考类型、音频、首尾帧或专用参数，由系列规范和具体平台版本确认；本文件不授予这些能力。
