# SOP-SCRIPT-XIANXIA 仙侠动作剧本作业指导

版本：1.0.0；层级：L3；发布：内部试运行；验证：结构审查。

## 适用与输入
适用于包含修行、法器、术法及战斗的仙侠剧情。输入人物动机、世界规则、能力与代价、门派关系、现有伤势和道具状态。视觉奇观必须对应人物行动或剧情信息。

## 具体步骤
1. 为冲突确定可判断的目标，如夺回物件、保护某人、拖延或逃离；胜负条件与单纯击倒区分。
2. 在本场写明角色已知能力、限制、消耗和环境条件；临时出现的新能力应有铺垫或承担明确后果。
3. 设计“试探—受阻—选择—改变局势”的行动因果。每次术法说明施动者、方向、目标和结果。
4. 将武器碰撞、身体接触、术法命中和环境破坏分别描述；特效只解释可见形态，不替代动作过程。
5. 把情绪放入决策：人物为保护、报复或信念牺牲什么，动作结束后关系如何改变。
6. 更新伤势、能力消耗、法器去向、暴露的秘密及阵营变化，供后续集与资产状态调用。

## 输出格式
剧本附世界规则引用、战斗目标、动作因果表、代价及战后状态；镜头层动作交给 SOP-SHOT-ACTION 展开，不在剧本中堆砌运镜指令。

## 检查与失败修复
检查每次反转是否有能力或环境依据，力量差距是否被行动策略解释。招式名难以可视化时补动作与结果；纯特效对轰时加入空间目标和选择；伤势消失或道具复原时修订连续性；信息过密时拆场，保留主角当下目标。

内部作业规范；结构审查不等于成片实测。
