# PR-SCRIPT 剧本开发程序

版本：1.0.0；层级：L2；发布：内部试运行；验证：结构审查。

## 目的与范围
将创作需求转为可拍摄、可拆镜、可追溯的原创剧本。适用于单集、系列及授权改编；模型能力与输出语法另由专用规范管理。

## 输入与责任
输入包括需求单、目标观众、时长目标、题材、已有设定、授权边界及历史集摘要。编剧负责创作和记忆更新；审核者检查因果、人物一致性及生产可行性；项目负责人确认需求变更。单人执行时分别保留创作与复核两次记录。

## 操作步骤
1. 建立需求基线，注明必需内容、禁改事实和未决项；不得把未知信息写成已确认事实。
2. 提炼主角目标、阻碍、选择及代价，形成大纲；每一场说明进入状态、冲突和离场变化。
3. 按所选风格 SOP 编写场景剧本。对白配合可观察动作，内心信息转换为表演或另行标记旁白。
4. 对照角色档案和历史事件逐项检查称谓、关系、知识范围、物品归属与时间顺序。
5. 估算声画占用，超出目标时长时删减或拆集；任何影响已批准设定的修改登记偏差。
6. 审核后冻结剧本版本，输出本集新增事实、未解问题及下一集交接摘要。

## 输出与验收
输出需求单、剧本、审核记录和跨集记忆增量。验收要求主线可复述、因果可追踪、人物行为有动机、场景有可见事件，素材引用可追溯；引用或改编内容有来源与使用边界。未经核验不得声称原创排查已完成。

## 异常与关联记录
信息缺失记为待确认；连续性冲突退回相关场景；审核未通过不进入资产定稿。使用 TPL-BRIEF、TPL-SCRIPT，按任务选择 SOP-SCRIPT-GENERAL 及对应题材 SOP。

内部作业规范；结构审查不等于成片实测。
