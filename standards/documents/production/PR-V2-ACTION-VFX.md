# 动作接触与特效因果设计程序

## 范围与输入
用于奔跑、跳跃、搏斗、变身、召唤、法阵及环境破坏等画面。输入必须包含角色位置、尺度、身体能力、装备、场景碰撞物、动作目标及幻想世界规则。真实物理与设定超自然作用分别记录，不能用“这是魔法”解释所有穿模或空间跳跃。
## 职责与前后关系
动作设计先定义重心和接触因果，特效设计为已明确的事件添加来源、传播与消散，摄影设计保证关键阶段可见，声音设计绑定可听见的接触。导演决定最重要的受力或信息瞬间；场记维护动作后的损伤、尘土和道具归属。
## 程序
1. 把动作拆为准备、启动、接触或越过障碍、反应、恢复及落点，建立每个角色的独立动作轨。
2. 标出支撑脚、受力方向、接触点及旋转轴；复杂招式先保留一个主因果，不同时要求所有人物连续换位。
3. 为特效建立触发条件、来源位置、形态、尺度、速度、遮挡、反射照明和消散方式。没有来源的全屏光团不能作为合格设计。
4. 检查层次：角色主体、武器、地面、烟尘和光效的前后关系，接触点不能在唯一关键时刻全部被遮没。
5. 排出声音的事件起点与余音，镜头冲击和音效不能早于无预兆的接触而误导因果；风格性提前需明确为主观设计。
6. 对复杂动作制作起、中、终关键姿态和状态表。若目标模型不能稳定完成，拆成准备、接触、结果的镜头组，并保留相同空间锚点。
## 检验
正例：剑刃抵住盾面，盾沿受力方向转开，持盾者后脚补一步，接触点火花短促散落后熄灭。反例：两人尚隔着半米，盾牌已爆裂，持剑手瞬间换边。返修应指出最先失效的阶段，先修空间和接触，再增加装饰特效。
## 输出
动作因果表、特效生命周期表、遮挡与交互光记录、终态连续性表及降级拆镜方案。纸面可执行性与生成成功率分别登记。

## 适用和证据边界

本文件是内部创作与检查规范，发布表示可以试用，不表示已经通过真实视频生成验证。时间、距离、强度等数值是本镜头的设计变量，需按画幅、角色比例、实测可辨性及目标模型调整。模型是否支持参考类型、音频、首尾帧或专用参数，由系列规范和具体平台版本确认；本文件不授予这些能力。
